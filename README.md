# Sanvedya Neware — Portfolio

This repository contains a lightweight, responsive, dark-themed personal portfolio website for **Sanvedya Neware**, a Computer Science Engineering student and aspiring software engineer.

The site is built using **plain HTML, CSS, and JavaScript**, focuses on clarity and readability, and is suitable for deployment via **GitHub Pages**.

---

## ✨ Features

- Dark-themed, minimal UI
- Responsive layout (desktop & mobile)
- Sections for:
  - About / Hero
  - Projects
  - Education
  - Technical Skills
  - Certifications
  - Contact
- Downloadable resume
- Contact form using `mailto:` (opens default email client)
- No external frameworks — fast and lightweight

## 🛠️ How to Update

### 🔹 Update Personal Info
- Edit text content directly in `index.html`
- Replace `profile.svg` with your own image (keep the same filename or update the `<img>` tag)

### 🔹 Update Resume
- Replace `Sanvedya_Neware.pdf` with a newer version
- Keep the filename the same to avoid changing links

## 🚀 Deployment (GitHub Pages)

1. Go to **Repository Settings**
2. Navigate to **Pages**
3. Under **Source**:
   - Branch: `main`
   - Folder: `/ (root)`
4. Click **Save**

Your site will be available at:
