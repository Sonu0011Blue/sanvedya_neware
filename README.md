# Sanvedya Neware — Portfolio

This repository contains a lightweight, dark-themed portfolio website for Sanvedya Neware. The site now includes extended sections for education, technical skills, online courses, certifications, awards, and participation in workshops and competitions.

Files
- `index.html` — Main page (updated with detailed Technical Skills, Education, Certifications, Awards & Participation)
- `style.css` — Site styles
- `script.js` — Minimal JS for contact form (opens mail client)
- `assets/images/profile.svg` — Placeholder profile image
- `assets/Resume (1).pdf` — Resume PDF (uploaded)

How to update
- To change the email used by the contact form, update `sanvedya@example.com` in `index.html` and `script.js`.
- Upload a newer resume file to `assets/Resume (1).pdf` to replace the resume.
- To edit certifications, awards, or courses, modify the relevant sections in `index.html`.

Deploy
- Enable GitHub Pages: Settings → Pages → Branch `feature/ui-improvements` (or merge to main) / root → Save
- Site URL (after merging to main): https://Sonu0011Blue.github.io/sanvedya_neware

Notes
- The uploaded resume PDF filename contains spaces and parentheses: `assets/Resume (1).pdf`.
